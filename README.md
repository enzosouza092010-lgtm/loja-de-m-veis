# Casa Nativa — Móveis & Colchões

Site demonstrativo feito com HTML, CSS e JavaScript puro. Inclui layout responsivo, navegação mobile, animações ao rolar a página, filtros de produtos, busca demonstrativa e sacola interativa com encaminhamento para WhatsApp.

## Visualizar
Abra `index.html` em um navegador. O site usa imagens hospedadas remotamente e fontes do Google Fonts; para exibir tudo, é recomendável estar conectado à internet.

## Antes de publicar para uma loja real
- Substitua “Casa Nativa” pelo nome real da loja.
- Troque o telefone de demonstração `5511999999999` em todos os links e no JavaScript pelo WhatsApp comercial, usando código do país + DDD + número, sem espaços ou símbolos.
- Atualize o e-mail, endereço, redes sociais e as informações de entrega/garantia conforme a política verdadeira da loja.
- Revise os preços e nomes dos produtos demonstrativos. Não publique valores ilustrativos como se fossem preços confirmados.
- Use fotografias próprias ou com licença apropriada e autorização de uso comercial.

## Publicar pelo GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em Build and deployment, selecione **Deploy from a branch**, branch `main` e pasta `/(root)`.
5. Salve e aguarde a publicação do GitHub Pages.

Observação: a sacola é uma demonstração front-end. Não existe pagamento, controle real de estoque, banco de dados ou pedidos registrados; o botão final apenas prepara uma mensagem para o WhatsApp.
